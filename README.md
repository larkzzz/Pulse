# Пульс

Веб-приложение для пациентов, которые лечатся дома после стационара: напоминает о лекарствах,
помогает связаться с врачом и быстро позвать помощь. Проект для ГАУЗ «Пестречинская ЦРБ».

## Как запустить

Нужен Python 3.11 или новее.

```bash
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --reload
```

На Windows вместо `cp` можно просто скопировать файл `.env.example` и назвать копию `.env`.
Если команда `python` недоступна, используйте `py -3`; для запуска — `py -3 -m uvicorn app.main:app --reload`.

Откройте http://localhost:8000 и войдите в демонстрационную учётную запись.

| Страница | Адрес |
|---|---|
| Главная пациента | http://localhost:8000/ |
| Кабинет пациента | http://localhost:8000/cabinet |
| Вход | http://localhost:8000/login |
| Регистрация по коду | http://localhost:8000/register |
| Заявка без кода | http://localhost:8000/register/no-code |

В режиме разработки данные хранятся в файле `pulse.db` (SQLite) и сохраняются после перезапуска.
Демонстрационные пользователи, коды и расписание создаются автоматически при первом запуске.
Для сервера в `DATABASE_URL` указывается PostgreSQL.

**Демонстрационный пароль для всех учётных записей:** `demo1234`.

| Учётная запись | Почта | Что происходит после входа |
|---|---|---|
| Пациент | `galina.smirnova@mail.ru` | Главная с лекарствами |
| Пациент с заявкой | `petrov@mail.ru` | Экран «Заявка на проверке» |
| Врач | `safin@pestrechi-crb.ru` | Переход к будущему кабинету врача |
| Администратор | `admin@pestrechi-crb.ru` | Переход к будущему кабинету администратора |

Коды для регистрации: `PLS-4827`, `PLS-3159`; `PLS-1206` — уже использован, `PLS-0988` — истёк.
Кабинеты врача и администратора будут добавлены следующими этапами.

## Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

Тесты используют отдельную базу SQLite в памяти и не меняют `pulse.db`.

## Открыть с телефона

Телефон и компьютер — в одной сети Wi-Fi:

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

На телефоне откройте `http://<IP-компьютера>:8000`.

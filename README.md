# Пульс

Веб-приложение для пациентов, которые лечатся дома после стационара: напоминает о лекарствах,
помогает связаться с врачом и быстро позвать помощь. Проект для ГАУЗ «Пестречинская ЦРБ».

## Как запустить

Нужен Python 3.11 или новее.

```bash
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --reload
```

На Windows вместо `cp` можно просто скопировать файл `.env.example` и назвать копию `.env`.
Если команда `python` недоступна, используйте `py -3`; для запуска — `py -3 -m uvicorn app.main:app --reload`.

Откройте http://localhost:8000 и войдите в демонстрационную учётную запись.

| Страница | Адрес |
|---|---|
| Главная пациента | http://localhost:8000/ |
| Справочный ИИ-помощник | http://localhost:8000/assistant |
| Помощь: 112, регистратура, ближайший ФАП | http://localhost:8000/help |
| Кабинет пациента | http://localhost:8000/cabinet |
| Кабинет администратора | http://localhost:8000/admin |
| Вход | http://localhost:8000/login |
| Регистрация по коду | http://localhost:8000/register |
| Заявка без кода | http://localhost:8000/register/no-code |

В режиме разработки данные хранятся в файле `pulse.db` (SQLite) и сохраняются после перезапуска.
Демонстрационные пользователи, коды и расписание создаются автоматически при первом запуске.
Для сервера в `DATABASE_URL` указывается PostgreSQL.

**Демонстрационный пароль для всех учётных записей:** `demo1234`.

| Учётная запись | Почта | Что происходит после входа |
|---|---|---|
| Пациент | `galina.smirnova@mail.ru` | Главная с лекарствами |
| Пациент с заявкой | `petrov@mail.ru` | Экран «Заявка на проверке» |
| Врач | `safin@pestrechi-crb.ru` | Переход к будущему кабинету врача |
| Администратор | `admin@pestrechi-crb.ru` | Заявки, коды, пациенты, врачи и справочники |

Коды для регистрации: `PLS-4827`, `PLS-3159`; `PLS-1206` — уже использован, `PLS-0988` — истёк.
В кабинете администратора можно выдавать и отменять коды, рассматривать заявки,
перезакреплять пациентов, создавать и блокировать учётные записи врачей, вести справочники ФАП и препаратов.
Кабинет врача и чат с пациентом будут добавлены на этапе 5.

## Настройка экрана «Помощь»

- Укажите рабочий номер регистратуры в `REGISTRY_PHONE` (полный номер с `+7` или `8`).
  Личные номера врачей не показываются.
- В **Админка → Справочники → ФАП** внесите проверенные адреса, телефоны и координаты входа.
  В свежей базе справочник ФАП пуст; в старой базе примеры с вымышленными адресами видны
  только администратору. При замене примера укажите проверенный адрес и координаты входа.
  Телефон сверьте с данными ЦРБ или оставьте поле пустым.
  Координаты нужны для поиска ближайшего ФАП по прямой. Геолокация пациента запрашивается по кнопке и не сохраняется.
- Геолокация работает по HTTPS или на `localhost`. При открытии с телефона по обычному HTTP
  доступен ручной выбор медпункта.
- Для карты внутри «Пульса» укажите браузерный ключ JavaScript API Яндекс Карт **v3**
  (`YANDEX_MAPS_API_KEY`). В поле **HTTP Referer** ключа укажите `localhost` для разработки
  и домен сайта для публикации. Для закрытого приложения проверьте условия лицензии Яндекса.
  Без ключа доступны поиск ближайшего медпункта, адрес, телефон и ссылка на Яндекс Карты.
  После поиска ближайшего медпункта маршрут строится от текущего места пациента; при ручном
  выборе точку отправления пользователь указывает в Яндекс Картах. Для маршрута нужен интернет,
  но API-ключ не требуется.

## Настройка ИИ-помощника

- В Yandex Cloud нужен каталог с подключённым биллингом, сервисный аккаунт с ролью
  `ai.languageModels.user` на каталог и его API-ключ с областью `yc.ai.languageModels.execute`.
  Заполните в `.env` `YANDEX_FOLDER_ID`, `YANDEX_API_KEY` и `YANDEX_GPT_MODEL`
  (имя доступной модели YandexGPT из каталога Yandex AI Studio, например `yandexgpt-5.1`).
  Перезапустите приложение. Ключ ИИ — не ключ Яндекс Карт.
- Без настроек страница открывается, но отправка вопросов отключена. Для проверки подключения
  используйте вымышленный общий вопрос, например «Как подготовиться к приёму у врача?».
- В «Пульсе» сохраняются последние 20 пар вопрос–ответ, доступные только самому пациенту.
  Пациент может удалить их кнопкой «Очистить переписку». При удалении учётной записи
  история тоже удаляется; блокировка закрывает доступ, но не стирает её. В Яндекс уходят новый вопрос
  и до трёх предыдущих пар, без полей профиля, полиса и расписания. Не вводите личные данные
  в текст вопроса. Приложение не пишет переписку в технические логи и передаёт Яндексу
  заголовок отключения логирования содержимого.
- Помощник даёт общую справку, не проверяет срочность обращения и не заменяет врача.
  Фильтры распознают только некоторые формулировки и не гарантируют безопасный ответ.
  Перед использованием с реальными пациентами согласуйте с ЦРБ медицинскую проверку
  сценариев, обработку данных и условия отправки текста во внешний сервис.

## Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

Тесты собираются только из `tests/`, используют отдельную базу SQLite в памяти,
не меняют `pulse.db` и не вызывают YandexGPT.

## Открыть с телефона

Телефон и компьютер — в одной сети Wi-Fi:

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

На телефоне откройте `http://<IP-компьютера>:8000`.

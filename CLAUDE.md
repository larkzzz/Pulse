# Пульс

Адаптивное веб-приложение для сопровождения пациентов ГАУЗ «Пестречинская ЦРБ» вне стационара:
напоминания о лекарствах, ИИ-помощник, вызов помощи и карта до ФАП, чат с врачом,
кабинеты врача и администратора.

Бизнес-аналитика (требования, архитектура, сценарии) — в ветке `buisness_analitic`:
`01_domain_analysis.md`, `02_problem.md`, `03_functionality_architecture.md`, `pulse_architecture.excalidraw`.
Перед новой функцией сверяйся с ней; если решение меняет требования — обнови аналитику в той же ветке.

## Стек (не менять без обсуждения)

- Python 3.11+, FastAPI, шаблоны Jinja2, HTMX (локальный файл), Bootstrap 5 через CDN.
- Свой JavaScript — только для Service Worker (push) и Яндекс Карт.
- База: SQLite в разработке, PostgreSQL на сервере (через SQLAlchemy, адрес в `DATABASE_URL`).
- Внешние сервисы: YandexGPT, Yandex SpeechKit, Яндекс Карты, Web Push, SMTP.

## Запуск и проверки

```bash
pip install -r requirements-dev.txt
cp .env.example .env          # один раз, потом заполнить ключи
uvicorn app.main:app --reload # http://localhost:8000
python -m pytest -q           # тесты — перед каждым коммитом
```

## Устройство кода

- `app/main.py` — создаёт приложение, сессии и подключает разделы.
- `app/config.py` — настройки из `.env`. Ключи и пароли только там, никогда в коде.
- `app/database.py`, `app/models.py` — подключение к SQLite/PostgreSQL и модели SQLAlchemy.
- `app/access.py` — текущий пользователь и разграничение ролей.
- `app/web.py` — шаблоны и `htmx_redirect`.
- `app/routers/` — маршруты по разделам: `auth` (вход, регистрация), `patient` (главная), `cabinet` (кабинет пациента), `admin` (кабинет администратора).
- `app/services/` — логика без привязки к HTTP: её и тестируем. `demo.py` заполняет базу в разработке.
- `app/templates/` — страницы; `partials/` — куски, которые перерисовывает HTMX.
- `app/static/css/pulse.css` — все стили, цвета заданы переменными в `:root`.
- `tests/` — pytest с отдельной SQLite в памяти: `test_services.py` (логика), `test_pages.py` (страницы и формы).

## Правила

- Экраны — по скиллу `.claude/skills/pulse-ui`: крупный шрифт и кнопки, одна главная кнопка,
  зелёный только для «принято», красный только для помощи. Проверять на 360px и на компьютере.
- Логику держим в Python (`services/`, маршруты), в шаблонах — только вывод.
- Все тексты для пользователя — по-русски, простыми словами, без медицинского жаргона и без «ошибка 400».
- ИИ-помощник никогда не ставит диагноз: каждый ответ с пометкой «Это справка, а не диагноз».
- Минимум персональных данных (152-ФЗ). Полис ОМС — только в заявке без кода.

## Git

- Автор коммитов — Никита Рукавишников. **Не добавлять** в коммиты строки `Co-Authored-By`
  и другие упоминания ассистента: в контрибьюторах репозитория должен быть только автор.
- Каждый этап — в своей ветке, в `main` через пулреквест. Сообщения коммитов — по-русски.

## План разработки

0. Подготовка: структура кода, `.env`, тесты. ← сделано
1. База данных, пароли, сессии, роли; перевод готовых экранов с `mock_data` на базу. ← сделано
2. Кабинет администратора: коды, заявки, пациенты, врачи, справочники.
3. Экран «Помощь»: 112, звонок врачу, ближайший ФАП на Яндекс Картах.
4. ИИ-помощник на YandexGPT.
5. Кабинет врача и чат врач–пациент (WebSocket), выдача кода с QR.
6. Напоминания: Service Worker, Web Push, сервис уведомлений, письма, SpeechKit.
7. Выкладка на сервер (HTTPS), доводка, демо-данные.

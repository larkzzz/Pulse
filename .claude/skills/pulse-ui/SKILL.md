# Пульс: правила интерфейса

Перед работой прочитай CLAUDE.md в корне проекта. Этот файл добавляет правила именно для экранов.

## Для кого
- Пациент: пожилой человек, телефон, мало опыта. Простота важнее красоты.
- Врач: компьютер, нужно быстро видеть, кто принимает лекарства, а кто нет.
- Администратор: компьютер, формы и таблицы.

## Стек (не менять)
Шаблоны Jinja2 + HTMX + Bootstrap (через CDN). Свой JavaScript только для Service Worker и Яндекс Карт.
Данные берём из базы через маршруты и сервисы, в шаблоны логику не кладём. Демонстрационное наполнение — `app/services/demo.py`.

## Внешний вид
- Пациентский интерфейс: шрифт от 18px, кнопки от 48px высотой, высокий контраст, минимальная ширина экрана 360px.
- Спокойная палитра: белый или светлый фон, один основной синий, зелёный только для «принял», красный только для помощи и тревоги.
- Одна главная кнопка на экран. Никаких скрытых меню, жестов и мелких иконок без подписи.
- Нижняя навигация пациента из четырёх пунктов: Главная, Помощник, Врач, Помощь.
- Кабинет врача шире: слева список пациентов, по центру выбранный пациент, справа чат.
- Анимации лёгкие и по делу: плавное появление сообщения, смена состояния кнопки «Принял». Уважай `prefers-reduced-motion`.
- Если подключён навык frontend-design, не уходи в «смелый и необычный» дизайн: здесь важнее читаемость и привычные элементы.

## Экраны
1. Вход и регистрация.
2. Главная пациента: ближайший приём, большая кнопка «Принял», список приёмов на сегодня.
3. Чат с ИИ-помощником: в каждом ответе строка «Это справка, а не диагноз. Обсудите с врачом».
4. Помощь: красная кнопка вызова помощи (112), ближайший ФАП, карта, «Позвонить врачу».
5. Чат с врачом.
6. Кабинет врача: список пациентов, режим приёма лекарств и отметки, чат.
7. Кабинет администратора: учётные записи врачей, закрепление пациентов, справочники (ФАП, препараты).

## Порядок работы
1. Один экран за раз. Сначала `base.html`, потом остальные.
2. Покажи, какие файлы создал или изменил, и объясни простыми словами, что в них.
3. Проверь экран на ширине 360px и на ширине компьютера.
4. Не добавляй функции, которых нет в списке экранов.
